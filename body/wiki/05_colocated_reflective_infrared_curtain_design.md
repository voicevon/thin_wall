## 摘要 (Abstract)

在针对 `body`（分选车厢）入口物料检测的自研探索中，前述的对射式方案（[04号文档](04_single_tx_multi_rx_light_curtain_design.md)）虽然光强冗余度极高，但客观上存在一个**机械与电气施工的痛点**：必须在输送通道**两侧**分别固定支架，且其中一侧的线缆必须穿过流水线底板或绕过皮带跨槽布线（跨度走线易受传送带机械刮蹭、安装耗时）。

为此，用户提出了一种极具工程巧思的全新架构：**同侧漫反射式平行光幕（Co-located Diffuse Reflection Array）**。

该方案将发射管与接收管（如 3发3收、3发4收）**集成安装在流水线的同一侧**，利用芦笋的近红外漫反射特性进行检测：
1. **无物料（空机）**：发射光束穿透通道打向对侧深处预设的**黑色吸光陷阱（Light Trap / 倾斜消光槽）**，对侧反射率 $\rho \approx 0$，同侧接收管**全暗、全部截止（Dark State）**；
2. **有物料（芦笋进入）**：芦笋作为天然生物漫反射体（近红外 940nm 反射率高达 $40\% \sim 60\%$），散射光返回同侧，高度相对应的 1 个或多个接收管被照亮导通（Light State），通过板载硬件线或电路输出物料在位信号。

本文深入推演了同侧漫反射方案的**近红外散射物理模型、阵列几何排布、三大致命失效防御（内部直通串扰、对侧反射假通光、湿润水膜镜面偏光）、单侧 3发4收 电路实现及 3D 打印消光工装**。

## 1. 物理机理与芦笋近红外散射特性

### 1.1 芦笋表面的近红外漫反射（Diffuse Reflection）机理

红外漫反射传感器能否可靠工作，取决于目标物体的**漫反射率（Albedo）**与**几何散射特征**：

```text
       【同侧漫反射光路拓扑图】
       
       [同侧一体化探头] (流水线左侧)                         [对侧黑色吸光光阱] (流水线右侧)
       ┌─────────────────────┐                               ┌─────────────────────┐
       │ [Tx1] 940nm 发射管  │ ───────── 投射光束 ─────────> │   倾斜 45° 哑光黑槽  │
       │  | 物理黑色遮光隔离板 │                              │   (光线被弹向上下壁，│
       │ [Rx1] 窄角接收管    │ <──────── 漫反射回波 ──────── │    绝不返回同侧探头!)│
       │                     │         (若有芦笋在位)        │                     │
       │ [Tx2] 940nm 发射管  │                               │                     │
       │  | 物理黑色遮光隔离板 │              ╭────────╮       │                     │
       │ [Rx2] 窄角接收管    │ ─────────────>│ 芦笋   │       │                     │
       │                     │ <·············│ (截面) │       │                     │
       └─────────────────────┘   回光导通    ╰────────╯       └─────────────────────┘
                                           (强漫反射体)
```

1. **近红外“红边”高反射特性**：芦笋属于新鲜嫩绿植物，其叶肉细胞与海绵组织对可见光（400~700nm）有叶绿素吸收，但对 **940nm 近红外光具有极强的多重漫散射（植物近红外散射特性）**，其平均漫反射率高达 **$\rho \approx 40\% \sim 60\%$**，回光信号极其充足；
2. **朗伯漫反射（Lambertian Scattering）**：芦笋表皮粗糙、布满纵向维管束纤维与微鳞片，当 940nm 光斑照射到表面时，反射光呈半球形均匀向四周漫散射，使得同侧接收管无论距离芦笋 $20\text{mm}$ 还是 $40\text{mm}$，均能捕获到可观的光能量。

## 2. 阵列拓扑：为什么“多发多收平行排布”优于“单发多收”？

在漫反射架构下，若仅使用 1 个发射管覆盖大范围，光强随距离呈四次方快速衰减（$I \propto 1/d^4$），边缘接收管信号会极其微弱。因此，**“3 发 3 收”或“3 发 4 收”多管交错/平行阵列**是漫反射的最佳结构。

### 2.1 推荐拓扑：垂直交错 3-Tx 4-Rx 平行阵列

在探头垂直方向上，自下而上布置 4 只接收管，并在其缝隙间布置 3 只发射管：

```text
高度 (Z)
 ▲
18mm ┼── [ Rx4 ] (接收管 4)  ──> 负责检测粗笋顶部 (Z = 15~22mm)
     │   [ Tx3 ] (发射管 3)  ──> 照射中上部
12mm ┼── [ Rx3 ] (接收管 3)  ──> 负责检测中等粗笋 (Z = 10~15mm)
     │   [ Tx2 ] (发射管 2)  ──> 照射中下部
 6mm ┼── [ Rx2 ] (接收管 2)  ──> 负责检测细笋与中笋 (Z = 5~10mm)
     │   [ Tx1 ] (发射管 1)  ──> 照射贴底区域
 1.5mm ┼── [ Rx1 ] (接收管 1)  ──> 核心负责细笋 (Z = 1.5~6mm，底沿留空 1.5mm)
 0.0mm ┴──────────────────────────────────────────────────────────────────> 传送带表面
```

### 2.2 粗细芦笋多通道反射覆盖模拟
- **细笋（$\phi 6\text{mm}$）紧贴底板通过**：
  - 发射管 $\text{Tx}_1$ 照射细笋下半截；
  - 细笋散射光被距其最近的 **$\text{Rx}_1$ 和 $\text{Rx}_2$** 强力接收并导通；
  - 上方的 $\text{Rx}_3、\text{Rx}_4$ 处于全暗；
  - **判定结果**：1号、2号收到，3号、4号没收到 $\to$ 经“逻辑或”合成，系统立即判定**物料在位**！
- **粗笋（$\phi 22\text{mm}$）通过**：
  - $\text{Tx}_1 \sim \text{Tx}_3$ 全部照亮粗笋大截面；
  - $\text{Rx}_1 \sim \text{Rx}_4$ 全部导通饱和；
  - **判定结果**：全通道高冗余触发。

## 3. 同侧漫反射式三大致命物理失效与攻关防御

漫反射传感器在工业界最大的难题是**“假触发”与“漏触发”**。本设计通过三项物理防御将其攻克：

### 3.1 致命陷阱 1：探头内部“直通串扰（Internal Crosstalk）”
- **失效机理**：发光管 $\text{Tx}$ 发射的光线，在传感器内部外壳缝隙、或前置亚克力透镜玻璃内表面发生反射，**还没照到物料就直接射入了同侧相邻的接收管 $\text{Rx}$**！导致无物料时系统就一直报错常通。
- **物理攻关解法（隔离舱壁设计）**：
  1. 每一个发光管与接收管之间必须用 **3D 打印黑色不透光实体隔板（厚度 $\ge 1.5\text{mm}$）完全隔开**；
  2. 严禁发射与接收管共用整块大透镜！必须各自独立开孔，并在孔前设计凸出隔离肋。

```text
       【俯视图：内部防直通串扰隔板设计】
          ┌───────┬───────┐
          │  Tx   │  Rx   │
          │ 发射管 │ 接收管 │
          └───┬───┴───┬───┘
              │ █ █ █ │ <--- 黑色遮光实体隔板 (厚 1.5mm)
              │ █ █ █ │
              └── █ ──┘
                  ▼ 凸出 2mm 遮光前唇 (彻底切断外表面折射串扰)
```

### 3.2 致命陷阱 2：对侧背景反光导致“误判有物料”
- **失效机理**：当流水线上空闲无料时，光线射向流水线对侧侧壁。如果对侧是金属原色滑槽、白色塑料或亮面皮带，光线反弹回同侧探头，误判为有物料！
- **物理攻关解法（对侧“45° 倾斜吸光光阱”）**：
  - 在对侧探头正对区域，设计一个**深 $15\text{mm}$、呈 $45^\circ$ 倾斜向下倾角的黑色吸光槽（Light Trap）**；
  - 投射到对侧的直射光打在 $45^\circ$ 斜面上，根据反射定律，光线被折射反射到底板或下方机架，**回向同侧探头的反射率 $< 0.5\%$**，彻底消灭背景虚假反射。

### 3.3 致命陷阱 3：湿润水膜镜面偏转导致“漏检”
- **失效机理**：刚洗过的芦笋表面有一层光滑水膜。如果光线垂直射入，水膜镜面反射角若偏开，可能会使回光避开某个特定的接收管；
- **物理攻关解法**：
  - 本方案采用 **多接收管阵列（4 只接收管纵向覆盖）**，并在探头内部将接收管轴线向发射管方向微向内偏转 $6^\circ$（聚光聚焦交汇在槽中 $30\text{mm}$ 处）；
  - 即使某一角度镜面偏转，由于植物表皮微观粗糙度依然存在大量漫散射，相邻的接收管必能捕获散射能量。

## 4. 关键风险深度剖析：三极管“工作在放大区”的致命隐患与加固方案

在直觉设计中，我们常假定光敏三极管非“截止（Cutoff）”即“饱和（Saturation）”。然而在农产品漫反射实际工况中，**光敏三极管极易在过渡期甚至常态下工作在“线性放大区（Active / Linear Region）”**！如果直接将三极管集电极接入 ESP32 数字 GPIO，会带来极高工程风险。

### 4.1 为什么漫反射工况下三极管必然会进入“放大区”？

```text
       【光敏三极管 NPN 伏安特性曲线与工作点漂移】
       IC (集电极电流)
        ▲
        │  饱和区 (Saturation)            线性放大区 (Active Region)
        │  VCE < 0.3V                     IC = β · Iph
        │  ┌───────────--------------------------------------------- Iph = 20μA (粗笋近距强反射)
        │  │        ╭───────────────────────── [Q1: 深度饱和 Q点, VCE ≈ 0.2V]
        │  │       ╭╯
        │  │      ╭╯------------------------------------------------ Iph = 4μA (细笋中距漫反射)
        │  │     ╭╯       ╭─────────────────── [Q2: 卡在放大区! VCE ≈ 1.8V]
        │  │    ╭╯       ╭╯
        │  │   ╭╯       ╭╯------------------------------------------ Iph = 1μA (微弱漫散射)
        │  │  ╭╯       ╭╯
        │  │ ╭╯       ╭╯
        └──┴┴───────┴───────────────────────────────────────────────> VCE
           0.3V   0.8V     1.5V      2.4V                 3.3V
                 [V_IL]  [禁区悬空]  [V_IH]             (截止区 Cutoff)
```

1. **光强非阶跃性（Continuous Analog Ramping）**：
   - 对射式光路被物料切断是“断崖式截光”，光电流瞬变，三极管开关迅速；
   - **漫反射式则完全不同**：芦笋从远及近切入光斑、或细笋（$\phi 6\text{mm}$）掠过时，反射光极其微弱且呈连续渐变，光生电流 $I_{ph}$ 从 $0 \to 1\mu\text{A} \to 4\mu\text{A} \to 20\mu\text{A}$ 缓慢爬升；
2. **临界饱和条件严苛**：
   - 设总上拉电阻 $R_L = 10\text{k}\Omega$，$V_{CC} = 3.3\text{V}$；
   - 想要三极管完全进入饱和区（$V_{CE} \le 0.3\text{V}$），集电极电流必须达到：
     $$I_{C(\text{sat})} = \frac{3.3\text{V} - 0.3\text{V}}{10\text{k}\Omega} = 0.30\text{mA} = 300\mu\text{A}$$
   - 若光敏三极管放大倍数 $\beta = 100$，要求基极光电流 $I_{ph} \ge 3\mu\text{A}$；
   - **典型失控工况**：当细笋（$\phi 6\text{mm}$）在 $35\text{mm}$ 距离通过时，由于圆弧面漫散射与距离衰减，反射光微弱，$I_{ph} \approx 1.5\mu\text{A}$，则集电极电流 $I_C = \beta \cdot I_{ph} \approx 150\mu\text{A}$；
   - 此时集电极母线输出电压为：
     $$V_{\text{out}} = V_{CC} - I_C \cdot R_L = 3.3\text{V} - (150\mu\text{A} \times 10\text{k}\Omega) = \mathbf{1.80\text{V}}$$

---

### 4.2 掉入放大区的“三大致命工程灾难”

如果 $V_{\text{out}}$ 悬浮在 $1.8\text{V}$ 并直接连接到 ESP32 的数字 GPIO：

1. **灾难 1：CMOS 逻辑电平“未定义禁区”与亚稳态振荡（Oscillation Jitter）**
   - ESP32 数字输入规范：
     - 低电平上限 $V_{IL} \approx 0.25 \times V_{DD} \approx 0.82\text{V}$；
     - 高电平下限 $V_{IH} \approx 0.75 \times V_{DD} \approx 2.47\text{V}$；
     - **$0.82\text{V} \sim 2.47\text{V}$ 属于逻辑电平绝对未定义的“亚稳态禁区”！**
   - 当节点电压在 $1.5\text{V} \sim 1.8\text{V}$ 缓慢穿越时，任何微弱的输送电机振动或电磁纹波，会导致 ESP32 内部输入反相器在毫秒内产生数十次**高低电平无序翻转（振荡连击）**，引起物料计数与中断完全错乱！
2. **灾难 2：细笋微弱反射无法触发（直接漏检）**
   - 细笋进入并反射了光线，但由于未能令三极管达到饱和，电压卡在 $1.8\text{V}$（大于 $V_{IL} = 0.82\text{V}$），**ESP32 判定仍为高电平，完全漏检！**
3. **灾难 3：环境温漂导致工作点剧烈漂移**
   - 光敏三极管暗电流 $I_{\text{CEO}}$ 和直流放大倍数 $\beta$ 具有极大的正温度系数（温度每升高 $10^\circ\text{C}$，暗电流几乎翻倍）；
   - 在放大区工作时，夏天高温下暗电流叠加可能使空机电压滑落至 $2.0\text{V}$ 从而诱发假报警，冬天低温时光电流衰减造成漏检。

### 4.3 工业级抗放大区根治方案一：外置 LM393 施密特比较器（推荐硬件解）

彻底根治放大区问题的标准硬件方案是：**严禁三极管直接驱动数字 GPIO，而是在传感器端加入 LM393 双路电压比较器，引入正反馈构建施密特触发器（Schmitt Trigger）**。

```text
  +3.3V ──┬────────────────┬───────────────────────────┬───────────────┐
          │                │                           │ 10kΩ          │
          │ 10kΩ           │ 100kΩ (分压基准)          │ 上拉          │
          ▼                ▼                           ▼               ▼
      [Rx1~Rx4 集电极]  [V_ref 阈值基准 ≈ 2.0V]      [LM393 比较器]    [LM393 电源]
          │                │                           │               │
          ├────────────────┼───────────── (-) 反相输入 │               │
          │                │                           │ OUT ──────────┴──> 直连 ESP32
          │                ├─── 100kΩ ─── (+) 同相输入 │                     GPIO 32
          │                │      │                    │                    (纯净数字电平)
          │                │      └── 1MΩ 迟滞正反馈 ──┤
          │                ▼                           │
       PT204-6B          100kΩ                        GND
        Q1~Q4              │
          │               GND
         GND
```

#### 工作机理与技术参数
1. **陡峭毫微秒翻转**：无论三极管集电极电压在放大区变化多么缓慢（例如从 3.3V 缓慢滑向 1.8V），只要跌破比较器阈值 $V_{TL} = 1.9\text{V}$，LM393 内部晶体管在 **$300\text{ns}$ 极速瞬间“咔嗒”翻转**，输出纯净的轨到轨 `0V`；
2. **正反馈迟滞回差消除抖动（$\Delta V \approx 150\text{mV}$）**：
   - 触发进入门限：电压跌破 $1.90\text{V}$ 时触发翻转；
   - 退出离开门限：回光减弱、电压必须回升超过 $2.05\text{V}$ 时才恢复高电平；
   - 彻底切断任何临界状态振荡连击；
3. **BOM 成本**：贴片 LM393 单价仅 **¥0.35 元**，整套硬件总成本依然在 **$< 8.50$ 元** 极低范围。

### 4.4 工业级抗放大区根治方案二：复用 ESP32 ADC1 模拟量采样 + 软件数字施密特滤波（零成本解）

如果不想在外围硬件增加比较器芯片，可以利用 ESP32 的硬件天赋特性实现**纯软件化解**：

> [!TIP]
> **ESP32 硬件引脚天赋**：  
> 在 `body` 单元中规划的 `ENTRY_SENSOR_PIN = GPIO 32`，在 ESP32 芯片内部原生就是 **`ADC1_CH4`（12 位高精度模拟量模数转换通道）**！

```text
  硬件连接：保持 4 只三极管并联母线直连 GPIO 32 (外围不增加任何比较器芯片)
  软件范式：将 GPIO 32 配置为 ADC 连续模拟量采样 (12-bit，读数 0 ~ 4095)
```

#### 软件数字施密特滤波器实现原理
将三极管工作在放大区的连续模拟电压视作**“极具价值的物料逼近模拟量”**：
- **空机无料**：暗电流极小，ADC 读数稳定在满量程附近（$3800 \sim 4095$）；
- **芦笋切入**：回光使电压下落，ADC 读数连续下跌；
- **固件中设定双门限判定算法**：
  ```cpp
  // 软件数字施密特触发器逻辑
  uint16_t adcVal = analogRead(32);
  
  if (!isOccupied && adcVal < 2000) {      // 跌破 2000 (约1.6V)，坚决锁定进入 (ENTER)
      isOccupied = true;
      onAsparagusEntered();
  } else if (isOccupied && adcVal > 3200) { // 回弹超过 3200 (约2.6V)，坚决锁定离开 (EXIT)
      isOccupied = false;
      onAsparagusLeft();
  }
  ```
- **核心价值**：
  1. 彻底绕开 ESP32 外部输入反相器的电平禁区与亚稳态；
  2. 软件迟滞门限可自由标定调整，即使细笋仅带来 $1.8\text{V}$ 的微弱变化，也能跨越 $2.0\text{V}$ 门限被 $100\%$ 锁定；
  3. 硬件外围物料成本增加 **0 元**！

## 5. 机械结构与 3D 打印一体化探头尺寸

同侧漫反射最大的工程优势在于**单侧一体化装配**：

```text
       【同侧 3-Tx 4-Rx 一体化探头机械剖面图】
       
       高度 25mm × 宽 18mm × 厚 12mm 极紧凑壳体
       ┌────────────────────────┐
       │ (M3 安装孔)            │
       │                        │
       │  [Rx4] 深 6mm 遮光深孔  │ ──> 顶部接收
       │  [Tx3] 发射孔          │
       │  [Rx3] 深 6mm 遮光深孔  │
       │  [Tx2] 发射孔          │
       │  [Rx2] 深 6mm 遮光深孔  │
       │  [Tx1] 发射孔          │
       │  [Rx1] 深 6mm 遮光深孔  │ ──> 距底面 1.5mm
       │                        │
       └───────────┬────────────┘
                   │ 3 芯屏蔽线 (VCC, GND, OUT) 直接引回 ESP32
                   ▼
```

1. **单侧接线**：全套传感器仅需引出 1 根 3 芯线缆（$3.3\text{V}$、$\text{GND}$、$\text{OUT}$），无需跨槽走线，流水线走线槽极其整洁；
2. **对光难度为零**：由于只装在单侧，完全不需要两侧对射管微米级精密对齐，螺丝一拧即装即用。

## 7. 方案总结与行动结论

1. **方案成立性确认**：
   - 用户提出的“**同侧平行排布、利用芦笋近红外高反射漫散射、多管任一收到即触发**”在物理光学上**完全成立**；
   - 细笋 $\phi 6\text{mm}$ 能够稳定照亮底部 1~2 个接收管，粗笋照亮全部通道，**检出率 $100\%$**；
2. **两项工程必做要点**：
   - 探头内部必须做**黑色实体隔板**，防直通内部串扰；
   - 流水线对侧必须设置**倾斜吸光光阱或黑色吸光植绒布**，杜绝空机反光；
3. **最大的工程价值**：
   - **单侧安装、单根三芯线、零对齐难度**，是机械设计施工最友好、成本最低的自制光幕方案。
