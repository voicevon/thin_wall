# 严禁自动提交 Git (No Automatic Git Commit)

本规则约束所有子项目与开发会话：

1. **禁止自主执行提交**：
   - 严禁在修改代码、重构、审查或修复问题后，自行运行 `git commit`。
   - 严禁代替用户做主合并或保存快照到版本历史。

2. **标准化交接流程**：
   - 在完成编码与测试验证后，停止工具调用；
   - 清晰列出修改文件及关键变动概览；
   - 等待用户检视；仅在用户明确指令要求提交时（或由用户自行手动在终端提交），方可协助执行提交。
