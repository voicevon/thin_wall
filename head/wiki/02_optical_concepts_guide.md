## 1. 概述与核心问题引出

在芦笋直径高精度在线测量（外径 $5\text{ mm} \sim 35\text{ mm}$，目标精度 $\pm 0.1\text{ mm}$）中，采用光学场测（如线阵 CCD 投影法）的核心挑战在于：**农产品在传送带上前行时，其高度、倾斜度及空间位置存在不可避免的浮动与跳动**。

若光学系统选型不当，传统的几何透视成像规律（“近大远小”）会使直径测量产生致命的假性尺寸漂移。本文对**物方视场 (FOV)**、**双远心镜头 (Bi-telecentric Lens)** 与 **微距定焦镜头 (Macro Fixed-Focal Lens)** 进行严谨的物理原理剖析与工程选型对比。

---

## 2. 物方视场 (Field of View, FOV)

### 2.1 物理定义与几何计算
物方视场（Field of View, FOV）指光学成像系统在物方工作距离（Working Distance, WD）下所能覆盖的实际物理空间范围尺寸。
- 在线阵 CCD 系统中，视场主要关注**一维线视场宽度** $W_{\text{FOV}}$（垂直于流水线输送方向，沿芦笋直径截面方向）。

$$W_{\text{FOV}} = \frac{L_{\text{sensor}}}{\beta}$$

其中：
- $L_{\text{sensor}}$：线阵 CCD 感光面有效物理长度（如 3648 像元 $\times 8\text{ }\mu\text{m} = 29.184\text{ mm}$）；
- $\beta$：光学系统垂轴放大率（Magnification）。当 $\beta < 1$ 时为缩小成像，$\beta > 1$ 时为放大成像。

```
                    物方视场 FOV 与成像传感器几何映射:
                    
  物方平面 (Object Plane)                     像方平面 (Sensor Plane)
      │◄─────── W_FOV ───────►│                       │◄──── L_sensor ────►│
      ┌───────────────────────┐                       ┌────────────────────┐
      │   传送带横向测量区    │ ===[ 光学物镜 β ]===> │   线阵 CCD 像元面  │
      └───────────────────────┘                       └────────────────────┘
                  ▲                                               ▲
                  │                                               │
             被测芦笋横截面                                 投影阴影像元区间
```

### 2.2 芦笋测径系统的 FOV 约束
1. **下限约束**：芦笋最大直径通常 $\le 30\text{ mm}$，加上物料在流水线横向放置时的机械定位偏差（$\pm 10\text{ mm}$），系统的 $W_{\text{FOV}}$ 必须设计在 **$50\text{ mm} \sim 60\text{ mm}$**，以确保任何偏摆均不超出感光区；
2. **分辨率与视场的权衡**：
   在固定像素数 $N$ 的情况下，单像元物理空间当量（Pixel Resolution）为：
   $$\text{Resolution} = \frac{W_{\text{FOV}}}{N}$$
   - 若 $W_{\text{FOV}} = 50\text{ mm}$，采用 $N = 3648$ 像元传感器，则每个像元仅对应 **$0.0137\text{ mm} \;(13.7\text{ }\mu\text{m})$**，天然满足超高精度检测需求。

## 3. 微距定焦镜头 vs 双远心镜头原理对比

### 3.1 微距定焦镜头 (Macro Fixed-Focal Lens)
微距定焦镜头是基于高斯成像几何原理设计的标准定焦透镜，对微小物距下的畸变进行了光学矫正。

```
             普通定焦镜头的透视视差现象 (近大远小):
             
       主光线 (有视场角 θ)
           \           /
            \         /
             \       /
         ─────[ 芦笋 A ]─────  物距更近 (突起)  ==> 成像投影偏大 (虚假变粗)
               \     /
                \   /
         ───────[芦笋 B]────── 物距标准平面     ==> 成像尺寸标准
                 \ /
                  ▼
              [ 镜头入瞳 ]
```

- **工作机制**：光线以锥形角度（存在视场角 $\theta$）射入镜头入瞳；
- **致命弱点（透视视差 / Perspective Error）**：
  - 物料上下浮动 $\Delta z$（例如粗芦笋比细芦笋的中心高度高出 $5\text{ mm}$，或者传送带颠簸跳动）时，主光线夹角会导致其在像面上的投影尺寸发生显著变化；
  - 测得的外径会伴随芦笋弯曲或弹跳产生 $0.3\text{ mm} \sim 0.8\text{ mm}$ 的系统漂移误差，难以通过纯软件算法滤除。

---

### 3.2 双远心镜头 (Bi-telecentric Lens)
远心镜头是专门为消除几何透视误差而诞生的精密计量级工业镜头。**双远心（Bi-telecentric）**意味着在**物方**与**像方**同时实现光瞳远心化。

```
             双远心镜头的平行主光线原理 (景深内尺寸恒定):
             
        物方平行主光线 (θ = 0°)                  像方平行主光线
        │             │                          │             │
        │  [ 芦笋 A ] │  (物距较近)              │             │
        │             │                          │             │
        │  [ 芦笋 B ] │  (物距标准)              │             │
        ▼             ▼                          ▼             ▼
       ┌───────────────┐        光阑孔径        ┌───────────────┐
       │ 物方前透镜组  │ ======> [孔径] ======> │ 像方后透镜组  │ =====> [ 线阵 CCD ]
       └───────────────┘       (位于焦平面)     └───────────────┘
```

#### 双远心核心物理优势：
1. **物方远心（Object-space Telecentricity）**：
   - 镜头的入瞳位于无穷远处，所有物方主光线**绝对平行于光轴**；
   - **完全消除“近大远小”效应**：在景深范围（Depth of Field, DOF，通常为 $\pm 3\text{ mm} \sim \pm 10\text{ mm}$）内，芦笋即便发生上下颠簸或不同弯曲高度，其成像阴影尺寸保持绝对恒定，放大倍率 $\beta$ 恒定；
2. **像方远心（Image-space Telecentricity）**：
   - 出射主光线同样平行于光轴射入 CCD 芯片像元；
   - 杜绝因 CCD 安装倾斜、法兰距离微小偏差或感光片位置公差导致的图像非均匀形变；
3. **超低光学畸变（Ultra-low Optical Distortion）**：
   - 工业级双远心镜头的畸变率通常 $< 0.05\%$（普通微距镜头通常在 $0.5\% \sim 2\%$ 之间）。

## 4. 光学照明配置：平行背光源 (Telecentric Backlight)

采用双远心镜头时，最佳搭配光源是**平行光背光准直器（Telecentric Illuminator）**，而非普通漫散射发光板（Diffuse Backlight）。

```
        普通漫射背光 vs 准直平行背光对圆柱体边缘的影响:
        
   [ 普通漫射发光板 ]                        [ 平行背光源 (Telecentric LED) ]
     \  |  /  \  |  / (光线杂乱散射)              │  │  │  │  │  │ (准直平行光束)
        │     │                                  │  │  │  │  │  │
      ╭─────────╮                                ╭─────────╮
      │ (芦笋)  │ 光线沿圆柱曲面绕射/折射        │ (芦笋)  │ 边缘切线垂直阻断，无绕射
      ╰─────────╯                                ╰─────────╯
        ↓     ↓                                  │         │
    阴影边缘模糊、带虚影过渡 (灰度爬坡缓)         锐利分明的阶跃跳变阴影 (陡峭边缘)
```

- **准直红光/绿光（525nm / 660nm）**：单色平行光不仅消除色散，还能极大地抑制由于芦笋半透明表皮引起的透光散射（Subsurface Scattering），使线阵 CCD 抓取到的电平跳变边缘极度陡峭，边缘识别重复度可达微米级。

## 5. 镜头选型与工程参数对比矩阵

| 对比维度 | 微距定焦镜头 (Macro Lens) | 物方远心镜头 (Object-Telecentric) | 双远心镜头 (Bi-telecentric) |
| :--- | :--- | :--- | :--- |
| **主光线特性** | 物方/像方均发散（锥形） | 仅物方主光线平行 | **物方与像方主光线均严格平行** |
| **近大远小透视误差** | 严重存在（物距浮动即漂移） | 消除 | **完全消除** |
| **有效工作景深 (DOF)** | 视光圈大小而定，但放大率漂移 | 放大率恒定，景深适中 | **放大率恒定，景深适中 ($\pm 5\text{ mm}$)** |
| **光学畸变率** | $0.5\% \sim 1.5\%$ (枕形/桶形) | $< 0.1\%$ | **$< 0.05\%$ (极高几何保真度)** |
| **物理尺寸与口径** | 紧凑小巧 ($\phi 30\text{ mm}$) | 前镜片直径必须 $>$ 视场 FOV | **前镜片直径必须 $>$ 视场 FOV (较粗重)** |
| **BOM 成本** | **低 ($\approx 100 \sim 200\text{ RMB}$)** | 中 ($\approx 400 \sim 800\text{ RMB}$)** | **较高 ($\approx 800 \sim 1500\text{ RMB}$)** |
| **芦笋测径推荐度** | 仅推荐于低成本粗测 | 良好备选 | **精密计量级首选 (高可靠性)** |

## 6. 工程选型指导原则

1. **若追求极高精度与零标定漂移**：
   - 优选：**双远心镜头 + 准直平行背光源**；
   - 镜头口径需大于物方视场：由于芦笋视场需 $50\text{ mm}$，需选配前口径 $\ge \phi 65\text{ mm}$ 的大口径远心物镜；
2. **若受制于空间安装尺寸与成本**：
   - 选用：**长焦距工业微距定焦镜头（如 $f = 35\text{ mm}$ 或 $50\text{ mm}$）**；
   - **工程补偿手段**：尽量拉大物距（$WD \ge 300\text{ mm}$），通过收窄入瞳张角来物理压缩透视失真；机械上配合聚四氟乙烯 (PTFE) 压轮或微 V 形槽限位，防止芦笋在检测截面垂直弹跳。
