## 1. 核心构想与系统范式转移 (Paradigm Shift)

### 1.1 现有分立式架构的工程局限
在当前的 `head` 单元架构中，**测长**与**测径**是由两套完全异构的子系统独立完成的：
1. **测长依赖“双颜色传感器 + 电机步数换算”**：
   - 依赖入口流水线安装的两个 TCS34725（间距 $D$），前哨传感器 1 发现白根后强制输送电机减速，主测传感器 2 捕捉绿白分界；
   - **痛点 A（机械打滑失真）**：若芦笋在传送带上有轻微滑动或滚动，累计电机步数换算的长度直接失效；
   - **痛点 B（必须强制减速）**：TCS34725 积分时间需 24ms，高速下空间分辨率严重劣质化，必须在减速工位减速至低速，严重制约流水线整机产能；
   - **痛点 C（结构冗长）**：传送带需要预留足够的加减速与两传感器安装间距 $D$（至少 50~100mm）。
2. **测径独立后置**：
   - 在颜色传感器下游单独设置测径工位。

### 1.2 彩色线阵 CCD 一体化方案的核心突破
如果将黑白单色线阵 CCD 升级为**三线阵彩色 CCD（RGB Tri-linear CCD）**，流水线即可实现**“一机双测、全速飞拍、融长径于一体”**的革命性重构：
- **物料高速匀速行进，彻底告别两个 TCS34725 颜色传感器**；
- **单相机同时获得“直径”、“有效绿长”与“总长度”**；
- 彻底省去“前哨预警、平滑减速、分界判定”等一系列繁复的运动控制状态机，传送带全程以最高速度单向推进；
- 获得整根芦笋沿轴线从头到尾的**完整连续形态学轮廓与真彩色云图**（不仅能测单点直径，还能输出头部直径、中部直径、尾部直径及弯曲度曲率）。

## 2. 物理测量原理与推扫式成像几何 (Push-Broom Imaging)

### 2.1 推扫式空间时域映射模型
芦笋平躺在传送带上，以恒定线速度 $v_x$ 沿 $X$ 轴通过光学测量截面。
彩色线阵 CCD 安装在侧方，其像元阵列沿垂直高度方向（$Z$ 轴）排布，以固定行频 $f_{\text{line}}$ 进行高速连续“推扫”（Push-Broom Scanning）。

设扫描行周期为 $T_{\text{line}} = 1 / f_{\text{line}}$，每扫描一行，芦笋在前进方向移动的物理位移步长为：
$$\Delta x = v_x \times T_{\text{line}} = \frac{v_x}{f_{\text{line}}}$$

若配置编码器硬件触发（Line-Triggered），使每前进 $\Delta x = 0.1\text{ mm}$ 触发曝光一行：
- 芦笋全长 $200\text{ mm}$ 将精确生成 **2000 行** 连续二维真彩色高精图像；
- **前进位移完全与传送带实际行进刚性绑定，彻底消除了输送电机加减速非线性与打滑带来的累积误差**。

```
                       推扫式彩色线阵成像数据阵列:
                       
   垂直高度 Z (像元序号)
      ▲
  top ┼─────────┌────────────────────────────────┐───────── (背景)
      │         │ 绿头    嫩绿茎体     绿白分界  │ 白根    │
      │ 阴影上沿 │ ███████████████████▒▒▒▒▒▒▒▒▒▒│░░░░░░░░░ │ 芦笋茎体 (遮挡)
      │ 阴影下沿 │ ███████████████████▒▒▒▒▒▒▒▒▒▒│░░░░░░░░░ │
  bot ┼─────────└────────────────────────────────┘───────── (背景)
```

### 2.2 几何外径与长度参数的联合提取公式

#### 1) 连续外径解算（各截面直径 profile）
在第 $k$ 行扫描中，沿 $Z$ 轴方向提取物料上下边缘对应的像元位置 $Z_{\text{top}}(k)$ 与 $Z_{\text{bot}}(k)$：
$$D(k) = |Z_{\text{top}}(k) - Z_{\text{bot}}(k)| \times K_z$$
- **标准截面直径**：取距芦笋绿头固定行数偏移处的数值：$D_{\text{spec}} = D(Line_{\text{start}} + N_{\text{offset}})$；
- **全笋形态参数**：可同步输出最大直径 $D_{\text{max}}$、最小直径 $D_{\text{min}}$、锥度及平均直径。

#### 2) 有效绿长与总长度解算
在每一行中，对芦笋表面感光区域的 RGB 像元进行色彩归一化色度判定。定义绿色特征指数 $I_g(k)$：
$$I_g(k) = \frac{G(k) - R(k)}{G(k) + R(k) + B(k)}$$
- **绿头进入判定**：当首次检测到物料且 $I_g > \text{Threshold}_{\text{green}}$ 时，标记扫描行 $Line_{\text{start}}$；
- **绿白分界判定**：沿行时序向后移动，当 $I_g(k)$ 持续跌破阈值并带回差确认时，锁定分界行 $Line_{\text{boundary}}$；
- **尾端离开判定**：当物料完全离开视场时，锁定离开行 $Line_{\text{end}}$。

**最终形态学尺寸直接由行数差乘上空间当量得出**：
$$\text{有效绿长} \; L_{\text{green}} = (Line_{\text{boundary}} - Line_{\text{start}}) \times \Delta x$$
$$\text{芦笋总长} \; L_{\text{total}} = (Line_{\text{end}} - Line_{\text{start}}) \times \Delta x$$

## 3. 光学照明系统升级：从“单纯阴影”到“透射/反射复合照明”

使用黑白单色线阵测径时，只需背后加背光源形成剪影；但**要测颜色，必须接收芦笋表面的反射光**。如果光路设计不当，表面反光会破坏轮廓边缘，或者背光太强冲淡色彩。

### 3.1 复合照明系统架构设计 (Hybrid Dual-Lighting)

```
        ┌─────────────────────────────────────────────────────────────┐
        │            彩色线阵 CCD 复合透/反射照明几何光路设计           │
        └─────────────────────────────────────────────────────────────┘

    [ 背光侧 (左侧) ]              [ 输送工位 ]               [ 相机侧 (右侧) ]
    
    窄带近红外/蓝背光源                                  高显色性高亮白色线光源
    (用于打透轮廓剪影)                                   (与光轴成 45° 照亮表面)
        ┌──────┐                                                ┌──────┐
        │ LED  │ ─── (水平背光) ───>                     <─── │ LED  │ (白色前向照明)
        └──────┘                    ╭─────────╮                 └──────┘
                                    │ 芦笋截面│                    │
                                    ╰─────────╯                    │
                                         │ 表面漫反射光            │
                                         ▼                         ▼
                                ─────────────────────────────────────
                                [ 垂直石英防污视窗 (带微吹气帘) ]
                                ─────────────────────────────────────
                                                 │
                                                 ▼
                                     [ 彩色双远心镜头组 ]
                                                 │
                                                 ▼
                                      [ RGB 三线阵 CCD 芯片 ]
```

1. **前向 45° 高显色性白色 LED 线光源（Color Reflection Light）**：
   - 专门负责照亮芦笋朝向相机一侧的茎体表面；
   - 选用显色指数 $\text{Ra} \ge 95$ 的高均匀性柱面聚光线光源，精确还原绿嫩组织与白根的反射光谱差异；
2. **透反射交替分时曝光 或 光谱分离方案**：
   - **最优方案（全白光漫反射 + 暗背景）**：
     左侧不加透射光源，而是采用**吸光黑色背景板**；右侧仅用高亮白光照射芦笋。在黑色背景的衬托下，芦笋表面反光既能提供清晰的亮绿色/白色图像，其与纯黑背景的交界处又构成了极其锐利的物理边缘轮廓，**一举兼得轮廓直径与表面真彩**！

## 5. 系统数据通量与主控算力瓶颈突破

### 5.1 数据吞吐率计算
若采用 TCD2569BFG（2592 像素 $\times$ 3 通道 = 7776 采样点/行）：
- 设流水线行频为 $f_{\text{line}} = 1.0\text{ kHz}$（每秒扫 1000 行，对应 $100\text{ mm/s}$ 输送速度下 $0.1\text{ mm}$ 分辨率）；
- 模拟采样点速率：$7.776\text{ Msps}$；
- 原始数据流带宽：$7.776\text{ MSPS} \times 2\text{ Byte (12-bit ADC)} \approx \mathbf{15.5\text{ MB/s}}$。

### 5.2 主控架构升级：普通 MCU 已无法承受
- **为什么 STM32F401 无法胜任？**
  F401 的片上 ADC 仅 2.4Msps，无法同时分时采样 3 个色彩通道，且片上 96KB SRAM 无法存储多行图像缓冲；
- **新一代嵌入式处理器架构推荐**：
  1. **方案 A（高端 MCU 级）：STM32H7 系列（如 STM32H743 / H723）**
     - ARM Cortex-M7 @ 480MHz，片上 1MB RAM，具备 3 个独立的超高速 16-bit ADC（单个达 3.6Msps，交织可达 7.2Msps），内置 MDMA 硬件链表搬运与硬件 JPEG/滤波加速器；
     - 可在片内以流水线方式一行一行计算边缘与色彩，仅需保留当前行的直径与颜色状态，无需保存完整大图，内存开销可压制在 32KB 以内！
  2. **方案 B（工业成熟级）：FPGA / 专用 DSP 智能线阵相机**
     - 选用国产紫光同创 / 高云小封装 FPGA 作为前端，负责三通道高速 ADC 采样与色彩归一化硬件流水线计算，直接通过 UART 输出精简结果。

## 7. 结论与工程落地路线建议

1. **技术可行性确定**：
   采用彩色线阵 CCD 彻底取代颜色传感器，在物理光学与数学几何上**完全成立且极其优越**。它一举消除了流水线减速瓶颈和机械打滑缺陷；
2. **渐进式演进策略**：
   - **当前阶段 (Phase 1)**：保持现有的 `head`（双 TCS34725）+ `ccd_eye`（黑白线阵 CCD 测径）工程闭环，确保流水线首期迅速交付投产；
   - **下一代升级 (Phase 2)**：启动彩色线阵一体化原型预研，采用 **Toshiba TCD2569BFG + STM32H7** 构建“色彩+轮廓双融合”智能工业相机。当该相机成熟后，只需拆除流水线上的 2 颗 TCS34725，即可无缝升级为新一代超高速全形态分级流水线。
