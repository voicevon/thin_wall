# ESP32 芦笋智能检测分选系统 (Thin Wall)

## 1. 项目简介与系统目标
本项目基于 **ESP32** 主控芯片，面向芦笋加工检测场景，构建集**双轴运动控制 (X轴推料 + Y轴测径)**、**双颜色传感器协同测长 (前哨降速 + 精准分界)** 与 **激光扫描测径** 于一体的智能测量系统。

### 核心测量目标
1. **芦笋有效长度 (绿长) 测量**: 精确测定芦笋头部到根部白化分界点之间的**绿色嫩茎有效长度**（单位：mm）；
2. **芦笋横向直径测量**: 通过 Y 轴垂直扫描与微光斑激光传感器，精确测定芦笋的**外径尺寸**（单位：mm）；
3. **数据对外通信交付**: 提供标准通信接口（UART / JSON / 自定义协议），将测量得到的有效长度与直径实时传输给下游分级/切根单片机或上位机。

## 2. 硬件架构组成

### 2.1 主控
- **MCU**: ESP32 开发板 (双核 240MHz，丰富硬件定时器与双硬件 I2C，满足高精双轴电机与实时传感采样需求)

### 2.2 传感器系统
1. **双 TCS34725 颜色传感器 (安装在入口流水线上，相距固定距离 $D$)**:
   - **传感器 1 (前哨预警)**: 接入 ESP32 硬件 `I2C_0`。负责物料放入触发启动，以及检测到白根进入时提前通知电机降速；
   - **传感器 2 (精测量基准)**: 接入 ESP32 硬件 `I2C_1`。负责物料头部品相确认、并在低速下高精捕捉绿白分界临界点；
   - **安装间距参数化 (已确认)**: 两传感器物理间距 $D$ 可任意调节，在 `config.h` 中通过 `SENSOR_DISTANCE_MM` (推荐默认 50mm) 宏集中配置，系统自适应规划降速斜率；
   - **积分时间与增益参数化 (已确认)**: 在 `config.h` 中通过宏参数配置 TCS34725 积分时间（默认 24ms 约 40Hz，兼顾高精空间分辨率与信噪比，可一键切为 2.4ms 极速档）与增益倍数（默认 4X/16X 可调）；
   - **独立双路补光控制 (已确认)**: 两个颜色传感器分别配置独立专属的接近补光灯控制电路：
     - **补光系统 1 (`LED_CTRL_1`)**: 专供传感器 1，物料进入入口时开启，负责前哨触发与白根预警照明；
     - **补光系统 2 (`LED_CTRL_2`)**: 专供传感器 2，芦笋到达主测位时开启，负责绿头判定与白根分界高精度照明；
     - **独立控光优势**: 杜绝两工位间强光串扰，降低单路持续发热，实现按需精细化光照管理。
2. **激光光斑测径传感器**:
   - 被动式/微光斑激光反射（或对射）检测器，搭载在 Y 轴滑台上；
   - 输出遮挡信号（数字电平），通过滑台移动过程中被遮挡的起止位移差计算直径。

### 2.3 运动执行系统 (双步进电机)
1. **X 轴送料电机 (连续单向传输/测长)**:
   - **驱动器**: A4988 步进驱动 (1/16 细分，STEP/DIR/EN 控制)；
   - **传动形式**: 连续单向传动机构 (如传送带/单向滑台，当量 **80 steps/mm**)；
   - **运动特性 (已明确)**: **纯单向移动，无往回复位 (无 Homing/不回退)**。仅有三种运行状态：
     - **停止 (IDLE/STOP)**: 待机等待物料放入；
     - **高速前进 (HIGH_SPEED)**: 芦笋入料后高速推进；
     - **低速平稳前进 (LOW_SPEED)**: 接收到前哨白根预警后平滑降速，供传感器 2 精密测长。
2. **Y 轴测径电机 (横向扫描/有 Homing)**:
   - **驱动器**: A4988 步进驱动 (1/16 细分)；
   - **传动形式**: 垂直于 X 轴移动的线性往复模组，带动微光斑激光探头横向扫过芦笋；
   - **运动特性 (已明确)**: **具备 Homing 原点限位**。上电或测径完成后自动回零复位。

### 2.4 电源架构
- **12V 统一供电**: 12V 直供两路 A4988 动力端 (`VMOT` 并联滤波电容)；经 DC-DC 降压输出 5V 供 ESP32，3.3V 供传感器逻辑，全系统共地。

## 3. 详细工作流程与协同机制

### 3.1 放入与启动流程
1. 人工作业或上料机构将芦笋**头朝前 (嫩绿头在前，白根在后)** 放入进料口；
2. 芦笋头部首先遮挡 **传感器 1**；
3. 传感器 1 侦测到物料放入，系统立即启动 **X 轴电机高速向前推进**；
4. 芦笋头部推进到达 **传感器 2**，传感器 2 读到绿色，确认头部品相与测长起始基准点 $X_0$。

### 3.2 动态前哨降速与精准有效长度 (绿长) 测量
```text
[进料入口]
   │
   ├──> 传感器1 (前哨) ──────────距离 D──────────> 传感器2 (主测) ───> 前进方向(X轴) ──>
   │    (物料先过1)                               (物料后过2)
   │
   │  [芦笋状态: 绿头朝前 ═══════════════════════════ 白根在后]
```
1. **高速前移**: 芦笋绿色茎体持续高速通过；
2. **前哨预警白根**: 当芦笋根部移动到 **传感器 1** 时，传感器 1 率先读到**白色 (白根进入)**；
3. **提前降速**: 系统接收到传感器 1 的变白信号后，立即控制 **X 轴电机平滑降速**；
4. **精细捕捉分界点**: 芦笋以平稳低速继续前进，**传感器 2** 在充足的时间窗口与高采样率下，极其细致地捕获绿白过渡临界点（从绿转白的一瞬间）；
5. **计算有效长度 (绿长)**:
   - 记录传感器 2 从“检测到绿头”到“检测到白根分界”期间 X 轴电机累计走过的脉冲数；
   - 换算公式:
     $$\text{Length}_{\text{green}} (\text{mm}) = \frac{\Delta \text{Steps}_{X}}{\text{STEPS\_PER\_MM}_X}$$
   - 将有效长度存入测量记录。
6. **送出物料与 X 轴停机判据 (已确认)**:
   - 捕捉完白根后，X 轴继续低速前移，直至**传感器 2 读数完全恢复空载背景底色**（芦笋尾部脱离）；
   - 脱离后，X 轴再额外前送一段**固定安全距离 (如 $50\text{mm}$)** 将芦笋彻底送入出料区/落料口；
   - X 轴电机立即停机 (STOP)，关闭补光 LED，系统重回 **IDLE 待机**，等待下一根放入。

### 3.3 Y 轴横向激光扫描与直径测量 (已确认)
1. **测径触发与 X 轴短暂停机 (避免斜向失真)**:
   - 传感器 2 捕捉到绿头后，X 轴推移设定距离（如到达预设测径工位中段位置），**X 轴电机主动短暂停机 (Pause)**；
   - 确保芦笋处于完全静止状态，消除运动抖动与倾斜扫描误差；
2. **Y 轴横向光栅扫描**:
   - 启动 **Y 轴步进电机** 驱动滑台横向扫过芦笋；
   - 记录激光光斑被芦笋边缘遮挡的起始步数 $Y_{\text{start}}$ 与恢复未遮挡的结束步数 $Y_{\text{end}}$；
3. **直径计算与恢复推进**:
   $$\text{Diameter} (\text{mm}) = \frac{|Y_{\text{end}} - Y_{\text{start}}|}{\text{STEPS\_PER\_MM}_Y}$$
   - Y 轴扫描完成后立即反转启动回零 (Homing)，同时 **X 轴电机恢复推进**，继续完成后续的白根识别或出料流程。

### 3.4 补光 LED 节能与光照一致性控制
- 进料前（待机状态）：关闭两路传感器 LED，降低温升，避免环境光干扰；
- 物料进入触发时：瞬间开启 LED，提供稳定的高显色性恒定光源；
- 检测完成并复位后：自动关闭 LED。

### 3.5 测量数据对外通信传输
- 提供标准通信接口（UART0 串口，波特率 115200，支持扩展 RS485/CAN/WiFi）；
- 每次检测完成输出标准结构化数据包（如 JSON 或固定帧格式）：
  ```json
  {
    "id": 1024,
    "green_length_mm": 185.4,
    "diameter_mm": 12.8,
    "status": "OK"
  }
  ```
### 3.6 异常与超时保护机制 (已确认)
- **极简工程原则 (YAGNI)**: 默认人工规范放料，系统不过度预设复杂的形状拦截算法，确保最大流畅度；
- **防空转与防卡料兜底**:
  - **最大前送位移限制**: 单次推进若累计位移超过预设安全上限 (如 $600\text{mm}$) 仍未恢复底色，强制停机 (STOP)；
  - **采样超时保护**: 若传感器采样连续异常或超时，X 轴停机并关闭补光 LED，串口打印保护告警，重置状态机回到 IDLE 待机。

## 4. 推荐 GPIO 引脚规划分配表 (ESP32)

| 功能分组 | 硬件功能 | 模块/设备 | ESP32 GPIO | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| **I2C 总线 0** | SDA0 / SCL0 | TCS34725 #1 (前哨预警) | GPIO 21 / 22 | 硬件 I2C_0 (固定地址 0x29) |
| **I2C 总线 1** | SDA1 / SCL1 | TCS34725 #2 (精测量) | GPIO 16 / 17 | 硬件 I2C_1 (固定地址 0x29) |
| **LED 补光控制 1**| LED_CTRL_1 | 传感器 1 专用接近补光 | GPIO 15 | 进料/前哨预警时受控开启 |
| **LED 补光控制 2**| LED_CTRL_2 | 传感器 2 专用接近补光 | GPIO 13 | 主测位/精细测长时受控开启 |
| **X 轴送料电机** | STEP / DIR / EN | A4988 #1 (X轴) | GPIO 18 / 19 / 23 | 单向脉冲、方向、使能控制 |
| **Y 轴测径电机** | STEP / DIR / EN | A4988 #2 (Y轴) | GPIO 25 / 26 / 27 | 往复扫描脉冲、方向、使能 |
| **Y 轴原点限位** | LIMIT_Y | 微动/光电限位 | GPIO 32 | **Y 轴回零信号输入** (唯一硬件限位) |
| **测径激光传感器**| LASER_SIG | 微光斑激光接收 | GPIO 33 | 遮挡输入信号 (高/低电平) |
| **状态指示/备用** | STATUS_LED | 状态指示灯 | GPIO 4 | 运行/故障指示 (预留) |
| **对外通信** | TXD0 / RXD0 | UART0 串口通信 | GPIO 1 / 3 | 上位机/下游单片机数据接口 |

## 6. 软件技术栈与构建管理 (已确认)
- **构建环境**: PlatformIO (`platformio.ini`)
- **开发框架**: Arduino Core for ESP32
- **依赖库 (轻量精简)**:
  - `adafruit/Adafruit TCS34725` (颜色传感器驱动)
  - `waspinator/AccelStepper` 或硬件定时器脉冲发生器 (高平滑度加减速控制)
