# 线阵 CCD 智能测径相机系统 (ccd_eye)

## 1. 项目简介与系统定位

`ccd_eye` 是 thin_wall 芦笋自动化分级流水线的**高精度非接触式视觉测径子系统**（“机器视觉之眼”）。
本项目独立于主控推进与分选单元，基于 **STM32**（STM32F401 / STM32G431）微控制器构建，专门负责驱动工业级线阵 CCD 传感器芯片、执行亚像素边缘解算，并通过标准工业 UART 串口向上游主控单元（`head`）交付高精度的芦笋外径测量值。

## 2. 核心技术指标与设计特色

1. **左右水平对射防污架构 (Horizontal Opposed Geometry)**：
   - 彻底摒弃上下对射结构，将平行背光源置于左侧，线阵 CCD 相机置于右侧；
   - 芦笋前进时附带的泥土、碎屑与水滴受重力作用**自然垂直沉降**至下方排渣槽，视窗与光路终身免受泥污覆盖。
2. **极速在线飞拍（零流水线停顿）**：
   - TCD1304 电子快门曝光时间 $0.2\text{ ms} \sim 0.5\text{ ms}$，彻底冻结 $200\text{ mm/s}$ 输送速度下的运动模糊；
   - 采样与解算单次全流程耗时 $< 3\text{ ms}$，无需启闭电机或停机扫描，单根芦笋吞吐节拍提升 100% 以上。
3. **超高空间测量精度**：
   - 采用 3648 像元高密度线阵传感器，物理像元尺寸 $8\text{ }\mu\text{m} \times 200\text{ }\mu\text{m}$；
   - 在 $45\text{ mm}$ 物方视场下，理论分辨率达 **$0.0123\text{ mm/pixel}$**，配合亚像素线性插值，系统测量精度达成 **$\pm 0.05\text{ mm}$**。
4. **主从解耦与极简数据交付**：
   - 协处理器独立承担纳秒级时钟产生与高速 ADC/DMA 采集；
   - 向上位机提供标准 ASCII/JSON 串口协议，主控仅需单条读取指令，零算力开销。

## 3. 硬件架构与选型规格

### 3.1 核心器件清单 (BOM)

| 模块分类 | 器件型号 / 规格 | 说明 |
| :--- | :--- | :--- |
| **主控 MCU** | **STM32F401CCU6** (ARM Cortex-M4 @ 84MHz) 或 **STM32G431KBU6** | 具备 2.4Msps~4.0Msps 高速 ADC、DMA 控制器及高级定时器 TIM1/2 |
| **感光元件** | **Toshiba TCD1304AP / DG** | 3648 点高密度一维线阵 CCD，感光面总长 $29.18\text{ mm}$，3.3V 逻辑供电 |
| **前端调理运放** | **TI OPA350** (或 MCP6022) | 38MHz 增益带宽积高速精密轨到轨运放，提供直流偏置减除与 $3\times$ 反相放大 |
| **光学系统** | **工业微距定焦镜头** ($f'=35\text{ mm}$ 或 $50\text{ mm}$) / **双远心镜头** | 垂轴放大率 $\beta \approx 0.65\times$，物方视场 $H_{\text{FOV}} = 45\text{ mm}$ |
| **背光源** | **准直狭缝平行背光源** (525nm 绿光或 660nm 红光) | 提供垂直均匀准直光束，抑制表皮次表面散射 |
| **隔离与通信** | 高速光耦 (6N137) 或数字隔离芯片 (CA-IS3082) | 隔离步进电机动力地噪声，保证高信噪比采样 |

### 3.2 接口引脚定义 (与 head 主控连接)

| 引脚名称 | 信号方向 | 电平标准 | 功能说明 |
| :--- | :--- | :--- | :--- |
| **VCC** | 输入 | 5.0V (DC) | 逻辑供电电源 (板载低噪声 LDO 转 3.3V) |
| **GND** | - | 0V | 电源地线 |
| **UART_TX** | 输出 (至 head RX) | 3.3V TTL | 向上位机发送单行测量结果 JSON 数据 |
| **UART_RX** | 输入 (由 head TX) | 3.3V TTL | 接收上位机控制命令 (如调光参数、标定触发) |
| **TRIG** | 输入 (由 head GPIO)| 3.3V TTL (下降沿) | 硬件微秒级触发飞拍输入引脚 |
| **READY** | 输出 (至 head GPIO)| 3.3V TTL | 状态就绪 / 测径完成中断输出引脚 |

## 4. 通信协议与报文规范

`ccd_eye` 采用与 thin_wall 工程全局风格一致的单行 JSON 通信协议，波特率默认 **115200 bps**（8-N-1），每包以 `\n` 结尾。

### 4.1 硬件触发应答流程
1. `head` 在输送电机推料至测径截面时，将 `TRIG` 引脚拉低 $10\text{ }\mu\text{s}$（或通过串口下发 `{"cmd":"measure"}\n`）；
2. `ccd_eye` 立即锁定曝光，并在 $2.5\text{ ms}$ 内完成解算，通过 `UART_TX` 回送单行 JSON：

```json
{
  "item_id": 1024,
  "diam_mm": 15.82,
  "top_px": 2840.35,
  "bot_px": 1550.12,
  "exp_us": 500,
  "status": "OK"
}
```

### 4.2 状态码 (`status`) 诊断字典

| 状态码 | 含义 | 说明与处理对策 |
| :--- | :--- | :--- |
| **"OK"** | 测量正常完成 | 芦笋阴影轮廓清晰，有效外径数值可信 |
| **"NO_OBJECT"** | 视场无遮挡 | 传送带上未检测到物料或过早触发 |
| **"OVER_RANGE"** | 遮挡尺寸超限 | 芦笋茎体超出视场，或多根堆叠卡料 |
| **"OVER_EXPOSURE"**| 像元大面积饱和 | 背光过亮或曝光时间过长，需下调曝光量 |
| **"LOW_CONTRAST"**| 阴影对比度过低 | **光学视窗被泥污严重覆盖**，提示人工清洁或增大吹气帘气压 |

## 6. 构建与开发指南

- **主控平台**: STM32F401CCU6 (WeAct BlackPill) / STM32G431KBU6
- **开发环境**: PlatformIO (`platformio.ini`) 或 STM32CubeIDE
- **固件核心架构**:
  - `Core/Src/ccd_timing.c`: 硬件定时器级联配置 (TIM1 输出 2MHz PWM，TIM2 生成 ICG/SH)；
  - `Core/Src/ccd_adc.c`: ADC 规则组 + DMA 乒乓双缓冲采集；
  - `Core/Src/diameter_dsp.c`: 动态阈值划分与双边亚像素插值算法；
  - `Core/Src/uart_comm.c`: 串口 JSON 协议解析与数据上传。
