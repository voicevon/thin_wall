## 1. 核心设计原则与工程痛点突破

### 1.1 农业物料恶劣工况：泥土与落屑挑战
绿芦笋从田间采摘后未经彻底水洗或表面仍附带有泥沙、根部粘泥、残枝以及水汽。在流水线高速输送过程中：
- **上下对射布局的致命缺陷**：
  若采用“光源在下、相机在上”或相反的垂直光路结构：
  1. 芦笋前行时掉落的泥渣、水滴会直接覆盖在位于下方的光学视窗或背光板表面；
  2. 极短时间内即可导致光通量急剧衰减、阴影基准畸变，甚至损坏光学镜头，日常运行中每隔数十根芦笋就需停机擦拭，**在工业量产中完全不可行**。
- **本方案架构决断：左右水平对射布局 (Horizontal Opposed Geometry)**：
  - 光源置于流水线**左侧**，线阵 CCD 工业相机置于流水线**右侧**；
  - 测量光束沿水平方向横向穿透测量工位；
  - 芦笋附带的泥土、残叶在重力作用下**自然垂直向下掉落**至下方的开放式排渣槽，左右两侧的光学视窗与重力沉降方向完全平行，杜绝污损积累。

## 2. 测量几何与光学坐标系定义

芦笋平卧在传送带上，沿流水线 $X$ 轴方向匀速推进。
- **$X$ 轴（输送前进方向）**：物料传输轴线；
- **$Y$ 轴（水平横向光轴）**：平行光从左侧射向右侧的光传播方向；
- **$Z$ 轴（垂直重力方向 / 测量敏化轴）**：**线阵 CCD 感光像元的物理排布方向**。

因此，芦笋在水平光束下投影到 CCD 感光面上的阴影高度，即为其**横截面的垂直外径 $D_z$**。由于芦笋茎体截面接近轴对称圆柱，该尺寸即为标准的等级外径指标。

## 3. 光学系统详细设计与计算推导

### 3.1 视场需求与传感器选型锁定

#### 1) 垂直物方视场高度 $H_{\text{FOV}}$ 确定
- 芦笋最大直径通常 $\le 30\text{ mm}$；
- 考虑输送托架厚度、跳动及垂直晃动公差（$\pm 5\text{ mm}$）；
- **锁定物方视场**：$H_{\text{FOV}} = \mathbf{45.0\text{ mm}}$。

#### 2) 传感器芯片选定：Toshiba TCD1304AP/DG
综合对比 [03 - 线阵 CCD 传感器选型与参数对照](03_linear_ccd_sensors_guide.md)：
- **像元数量**：$N = 3648$ 像元；
- **像元尺寸**：$p_z = 8\text{ }\mu\text{m}$（高 $200\text{ }\mu\text{m}$，感光长度方向沿 $Z$ 轴）；
- **感光面总长度**：$L_{\text{sensor}} = 3648 \times 0.008\text{ mm} = \mathbf{29.184\text{ mm}}$；
- **核心优势**：3.3V 兼容，内置电子快门，像元密度极高，抗过曝能力优异。

---

### 3.2 光学放大率与分辨率计算

#### 1) 垂轴放大倍率 $\beta$
$$\beta = \frac{L_{\text{sensor}}}{H_{\text{FOV}}} = \frac{29.184\text{ mm}}{45.0\text{ mm}} \approx \mathbf{0.6485}$$
光学系统需设计为缩小倍率 $\beta \approx 0.65\times$。

#### 2) 理论空间像元分辨率（Pixel Resolution）
$$R_{\text{pixel}} = \frac{H_{\text{FOV}}}{N} = \frac{45.0\text{ mm}}{3648} \approx \mathbf{0.0123\text{ mm/pixel}} \;(\mathbf{12.3\text{ }\mu\text{m}})$$
- 单个像元仅代表 $0.0123\text{ mm}$，远优于项目要求的 $\pm 0.1\text{ mm}$ 精度指标；
- 即使采用最简单的整像素二值化，量化误差也仅为 $\pm 0.012\text{ mm}$；配合边缘线性插值，可轻松达成 $\pm 0.005\text{ mm}$ 亚像素精度。

---

### 3.3 镜头设计与共轭光路推导

#### 方案 A：工业微距定焦镜头（高性价比方案）
选用焦距 $f' = 35\text{ mm}$ 的低畸变工业镜头：
1. **物距（工作距离 $WD$，芦笋中心至镜头主面）**：
   $$WD = f' \times \left(1 + \frac{1}{\beta}\right) = 35 \times \left(1 + \frac{1}{0.6485}\right) \approx 35 \times (1 + 1.542) \approx \mathbf{89.0\text{ mm}}$$
   为避免光机外壳侵入传送带干涉区，可外接标准接圈或选用焦距 $f' = 50\text{ mm}$ 镜头：
   若 $f' = 50\text{ mm}$，则：
   $$WD = 50 \times \left(1 + \frac{1}{0.6485}\right) \approx \mathbf{127.1\text{ mm}}$$
2. **像距（镜头主面至 CCD 芯片表面）**：
   $$L_{\text{image}} = f' \times (1 + \beta) = 50 \times (1 + 0.6485) \approx \mathbf{82.4\text{ mm}}$$
3. **共轭物像总距离**：$L_{\text{total}} = WD + L_{\text{image}} \approx 209.5\text{ mm}$，机箱左右宽度仅需约 $280\text{ mm}$，结构紧凑。

#### 方案 B：双远心计量镜头（高精度抗跳动终极方案）
- 选用定制标称放大率 $\beta = 0.65\times$ 的**双远心工业镜头**；
- 物方工作距离固定为 $WD = 110\text{ mm}$；
- 物方工作景深：$DOF = \pm 6.0\text{ mm}$（在芦笋横向漂移 $\pm 6\text{ mm}$ 范围内，直径示值漂移 $< 0.01\text{ mm}$）；
- 远心度：$< 0.05^\circ$；
- 畸变率：$< 0.03\%$。

---

### 3.4 飞拍运动模糊与曝光时间设定

芦笋随流水线在 $X$ 轴以速度 $v_x$ 持续推进，测量在行进中触发（飞拍）。
- 设流水线高速档速度：$v_x = 200\text{ mm/s}$；
- 设 TCD1304 电子快门曝光时间为 $t_{\text{exp}} = 0.5\text{ ms} \;(500\text{ }\mu\text{s})$；
- 曝光期间芦笋前行位移：
  $$\Delta x = v_x \times t_{\text{exp}} = 200\text{ mm/s} \times 0.0005\text{ s} = \mathbf{0.10\text{ mm}}$$

#### 关键几何分析：
由于光束沿 $Y$ 轴传播，CCD 阵列沿 $Z$ 轴排布，芦笋在 $X$ 轴（沿切向）移动 $0.1\text{ mm}$ 时，其在该微小弧段内的轮廓直径变化量 $\Delta D \approx 0$。因此：
- **$0.5\text{ ms}$ 的短曝光完全能够冻结运动，测得极为锐利的边缘投影**；
- 彻底省去了方案一所需的“减速、停机、等待电机残余振动衰减、扫描、回零”等一系列机械过程，节拍收益巨大。

## 4. 机械防尘防污与结构防护设计

为保证系统在农业粉尘、泥浆环境下的长期免维护性，左右水平视窗需实施以下结构强化：

```
                    左右光学视窗防护结构剖面图:
                    
           [ 清洁正压空气输入 (~0.05 MPa) ]
                          │
                          ▼ (内腔气道)
             ┌─────────────────────────┐
             │    透镜 / 光源保护腔     │
             │                         │
             │   [ 光学玻璃窗口片 ]     │
             └───┬─────────────────┬───┘
                 │ 环形微吹气狭缝 (Air Knife)
                 ▼ 持续向下/向外吹气
          ═══════════════════════════════ (形成空气隔离屏障)
                 │
                 │ 外部工位 (飞溅泥沙/水雾被气流吹阻，无法粘附玻璃)
```

1. **垂直石英保护视窗**：
   在左侧平行光源和右侧镜头前端分别加装易更换的防刮抗污石英平晶玻璃（带双面增透镀膜）；
2. **微正压微吹气帘（Air Knife Curtain）**：
   引入微型气泵在视窗玻璃外侧形成持续微风气帘（0.02~0.05 MPa），不仅持续吹离悬浮粉尘，且彻底隔绝水汽凝结；
3. **物料通过区深底落料槽**：
   芦笋下方采用开放式深槽设计，底部倾斜导流至机身下侧接渣盒，人工每日只需抽屉式倒渣一次，测量光路终身免清洗。

### 5.2 软件边缘拟合算法（亚像素推导）
1. **暗电平与不均匀性校准**：
   系统开机无料时采集一帧空载波形 $V_{\text{blank}}(n)$ 作为背景基线；
2. **归一化阴影投影率**：
   $$T(n) = \frac{V_{\text{raw}}(n) - V_{\text{dark}}}{V_{\text{blank}}(n) - V_{\text{dark}}}$$
3. **阈值穿越与亚像素位置解算**：
   设定判据阈值 $T_{\text{th}} = 0.5$。在阴影跳变沿通过线性插值获取非整数像素位置：
   $$n_{\text{edge}} = n_k + \frac{0.5 - T(n_k)}{T(n_{k+1}) - T(n_k)}$$
4. **直径输出**：
   $$D = |n_{\text{edge\_top}} - n_{\text{edge\_bottom}}| \times R_{\text{pixel\_calibrated}}$$

## 7. 结论与工程实施准则

1. **彻底解决节拍约束**：
   相比方案一（机械滑台往复），左右水平线阵 CCD 系统在 $0.5\text{ ms}$ 内完成测量，**单次节省流水线停顿时间 600~1000ms**，整机吞吐率提升 100% 以上；
2. **彻底攻克农业泥污顽疾**：
   左右水平对射布局结合垂直重力自然沉降，从根本上排除了上下对射光路镜头被泥沙水滴遮蔽的行业通病；
3. **软硬件平滑解耦**：
   采用独立的前置采集板通过 UART 交付测量结果，使 `head` 原有 ESP32 代码逻辑无需大改，仅需将 Y 轴步进控制逻辑置换为一条读取数据指令。
