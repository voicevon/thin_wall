## 1. 概述

在光学投影式直径测量系统中，**线阵 CCD（Linear Array Charge-Coupled Device）**承担着将空间光学阴影直接转换为离散电荷电信号的核心任务。
不同型号的线阵 CCD 在像元数量、像元物理尺寸（纵横比）、感光面有效长度、工作电压、驱动时序复杂度以及输出信号幅度上存在本质差异。

本文针对工业测量领域最经典、性价比最高的几款主流线阵 CCD 芯片（**Toshiba TCD1304**、**Toshiba TCD1209** 以及 **Sony ILX511B**）进行全方位参数列举与工程对比。

## 3. 各型号芯片特性深度剖析

### 3.1 Toshiba TCD1304AP / DG：高密度分辨率王者
- **最大亮点**：
  1. **3648 巨量像元**：在同为约 $29\text{ mm}$ 的有效视场下，其像元间距缩减至 $8\text{ }\mu\text{m}$，物理几何量化分辨率比 2048 像素芯片高出近 **80%**；
  2. **3.3V 逻辑电平兼容**：工作电压典型为 3.3V，与 ESP32、STM32 等现代低功耗 MCU 逻辑直接电平匹配，无需复杂的电平转换芯片；
  3. **内置电子快门（Electronic Shutter）**：通过在读取周期中间注入额外的 $\text{SH}$ 脉冲，可以在光照极强时将曝光时间压缩至微秒级，完美防止背光强光下发生像素溢出电荷（Blooming）。
- **工程难点**：
  - 饱和输出电压较低（约 $500\text{ mV}$），输出阻抗较高，通常需要紧贴芯片设计一级运算放大器（如 OPA350 / AD8065）做阻抗变换与增益放大，才能送入 ADC 采集。

---

### 3.2 Toshiba TCD1209DG：传统工业正方像元
- **最大亮点**：
  - 像元为 $14\text{ }\mu\text{m} \times 14\text{ }\mu\text{m}$ 正方形，几何对称性好；
  - 饱和电荷容量大，输出信号幅值大（$> 1.5\text{ V}$），信噪比高。
- **工程难点**：
  - 需要 $+12\text{V}$ 模拟供电以及两相交叠驱动时钟（$\phi 1, \phi 2$），硬件供电与驱动电路设计繁琐，已逐步被单电源芯片替代。

---

### 3.3 Sony ILX511B：最友好的嵌入式线阵传感器
- **最大亮点**：
  1. **驱动极其简单**：芯片内部集成了时序脉冲发生电路，外部仅需提供**单相时钟 $\text{CLK}$** 和一个**读出触发门脉冲 $\text{ROG}$** 即可自运转；
  2. **高灵敏度与大输出幅度**：$14\text{ }\mu\text{m} \times 200\text{ }\mu\text{m}$ 的大受光面积带来了高达 $250\text{ V}/(\text{lx}\cdot\text{s})$ 的灵敏度，输出电压高达 $2\text{ V}$，普通 MCU 的内置 ADC 可直接无运放采集；
  3. **单 5V 统一供电**：与工业标准传感器电源高度契合。
- **工程选型建议**：如果项目采用自制微处理器从机开发板，**ILX511B 的软件和外围电路开发门槛最低**。

## 4. 驱动与信号采集关键链路

```
            线阵 CCD 信号采集典型硬件链路:

   [ 主控定时器 (TIM/PWM) ] ─── 产生驱动时序 (CLK, SH/ROG, ICG)
                                           │
                                           ▼
                                 ┌───────────────────┐
                                 │   线阵 CCD 传感器   │
                                 └─────────┬─────────┘
                                           │ 模拟视频输出 (OS)
                                           ▼
                                 ┌───────────────────┐
                                 │ 高速精密运算放大器│ (直流偏置与幅度放大)
                                 └─────────┬─────────┘
                                           │
                                           ▼
                                 ┌───────────────────┐
                                 │ 高速 ADC + DMA    │ (采样率 ≥ 1Msps)
                                 └─────────┬─────────┘
                                           │ 数字一维阵列
                                           ▼
                                 ┌───────────────────┐
                                 │ 动态双阈值边缘提取│ ===> 导出被测芦笋直径
                                 └───────────────────┘
```

1. **时序确定性要求**：
   线阵 CCD 的曝光时间由时钟脉冲严格决定。若产生脉冲的 MCU 发生中断抖动或系统延迟，会导致输出基线漂移、暗电流积累变动。因此必须使用**硬件定时器硬件 PWM 输出**或硬件 SPI 移位产生时钟。
2. **ADC 采样匹配**：
   以 2MHz 时钟、3648 像素为例，完整一帧输出耗时约 $1.8\text{ ms}$，ADC 瞬态采样率需达到 $2\text{ Msps}$。这正是方案论证报告中**不推荐 ESP32 裸跑直采**、而建议采用**专用采集协处理器或成品智能模组**的核心工程根源。

---

## 5. 选型决策总结

- **最高测量精度首选**：**Toshiba TCD1304AP / DG**（像元更多、间距仅 $8\mu\text{m}$、带电子快门、3.3V 兼容）；
- **极简工程验证首选**：**Sony ILX511B**（两线控制、信号幅值高达 2V、内置时钟逻辑、免去外置高倍运放）。
