# thin_wall 芦笋智能检测与分级分选系统

本项目是一套面向农业与食品加工场景的**分布式双 ESP32 芦笋智能流水线检测与分选系统**。
系统采用前后端解耦的模块化架构，由两个独立的 ESP32 子系统协同工作：前端入料识别定位系统 (**`head`**) 与后端分选分发机构 (**`body` / Dealer**)。

---

## 1. 总体架构设计

流水线物料方向：**进料 ➔ 前端检测与定位 (`head`) ➔ 节点交接 ➔ 后端分流与分级分发 (`body`) ➔ 多通道出料**。

```mermaid
graph LR
    In[芦笋人工/机械入料] --> Head["【head】前端识别定位主控 (ESP32)"]
    subgraph HeadSystem [head 子系统]
        Head --> S1[双颜色传感器: 绿长/白根识别]
        Head --> S2[Y轴激光模组: 横向测径]
        Head --> M1[X轴步进电机: 定位与入料推移]
    end
    Head -- "数据通信 (UART / 规格与分级指令)" --> Body["【body】后端分选分发主控 (ESP32 / Dealer)"]
    subgraph BodySystem [body 子系统]
        Body --> D1[多通道分流机构 / Dealer 分牌器]
        Body --> D2[执行机构: 舵机/步进道岔/推料机构]
        Body --> D3[各等级出料仓 (特级/一级/二级/次品)]
    end
```

## 2. 子项目职责划分

### 2.1 `head` —— 识别、测长、测径与定位入料系统
- **主控芯片**：ESP32
- **核心职责**：
  1. **物料感知与入料推进**：检测芦笋入料，驱动 X 轴单向步进电机平稳送料定位；
  2. **有效长度（绿长）测量**：利用双 TCS34725 颜色传感器（前哨预警 + 精测量基准），实现动静态平滑降速并精准捕获绿白分界临界点；
  3. **横向直径测量**：结合 Y 轴往复滑台与微光斑激光传感器，横向光栅扫描测定外径尺寸；
  4. **独立补光控制**：双路专属 LED 补光，按工位独立启闭，避免强光串扰并降低功耗温升；
  5. **数据对外交付**：将芦笋的唯一序号、有效长度（mm）、外径（mm）及测量状态打包发送给下游。
- **详细文档与引脚配置**：参见 [head/README.md](head/README.md)。

---

### 2.2 `body` —— 芦笋分级、分流与分发机构 (Dealer)
- **主控芯片**：ESP32
- **核心职责**：
  1. **数据接收与解析**：实时监听并解析来自 `head` 的通信数据包（有效绿长、外径尺寸、品质判定等）；
  2. **分级决策**：内置规格分级算法，根据预设行业标准或用户自定义规则，将芦笋匹配映射至对应出料通道（如特级品、一级品、二级品、加工原料、次品等）；
  3. **执行机构控制 (Dealer 机构)**：
     - 控制多通道分选道岔（舵机/步进电机/电磁阀/气缸等执行元件）；
     - 实现类似于“发牌器 (Dealer)”的平滑分支分流，将芦笋精准拨送/导流至目标滑道或料盒；
  4. **时序与流速同步**：跟踪流水线节拍与工位交接延迟，保证物料到达分流节点时执行机构已到位；
  5. **料仓状态管理**：监控各通道满料检测与系统异常联锁保护。
- **详细文档**：参见 `body/README.md`（规划建设中）。

## 3. 子系统间通信协同规范

两个 ESP32 节点通过有线串行接口（默认 UART0/UART2，可选 RS485 或 CAN）实现高可靠数据互通：

### 3.1 典型数据报文格式 (JSON)
`head` 完成单根芦笋测量后向下游 `body` 广播：
```json
{
  "item_id": 1024,
  "green_length_mm": 185.4,
  "diameter_mm": 12.8,
  "status": "OK",
  "suggested_grade": 1
}
```

### 3.2 协同状态同步时序
1. **Head 就绪**：等待放料 ➔ 触发推进 ➔ 测长与测径完成；
2. **数据交付**：Head 发送测量结果包至 Body；
3. **Body 准备**：Body 校验数据，根据目标等级提前将分流道岔拨动至就绪位；
4. **物料交接**：Head 的 X 轴将芦笋送出并交接至 Body 传输区间，Body 执行物料分发归仓。

## 5. 软件与技术栈

- **构建系统**：PlatformIO
- **开发框架**：Arduino Core for ESP32
- **编程语言**：C / C++ (C++14/17)
- **架构原则**：
  - **松耦合**：`head` 与 `body` 职责边界明确，独立编译、独立部署、通过协议解耦；
  - **YAGNI 原则**：杜绝过度封装与无必要抽象，保持轻量高效与工业级实时性。
